# Tienda Coolstuff

Descubre productos elegidos por su diseño, ingenio y utilidad, y cómpralos con entrega a domicilio en Colombia.

## Qué ofrece

- Una selección curada de gadgets, accesorios y artículos para el hogar.
- Compra sencilla, con pago contra entrega.
- Una experiencia ligera que funciona directamente en el navegador.

## Enlaces

- Tienda en línea: https://coolstuff-store.netlify.app
- Eraso M Labs: https://erasomlabs.netlify.app

## Estructura

- `index.html` y `assets/`: tienda en línea desplegada en Netlify.
- `seccion/`: sección HTML para androidcreator24.
